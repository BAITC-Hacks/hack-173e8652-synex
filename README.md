# Freedom MoneyGraph AML

Freedom MoneyGraph AML — локальная система объяснимой графовой аналитики для приоритизации AML-проверок по обезличенной сети внутрибанковских переводов. Источник требований, методология запуска и критерии проверки зафиксированы в [`prompt.md`](prompt.md) и [`docs/implementation_plan.md`](docs/implementation_plan.md).

Проект работает в режиме активной реализации; этот README будет дополнен только фактически проверенными командами, метриками и возможностями после полного запуска на предоставленных данных.
